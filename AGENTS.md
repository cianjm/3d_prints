# 3D print project organization

For each 3D print design, create a dedicated project directory directly inside the repository root. Within it, keep printable STL files together in one subdirectory, design assets (such as images and other non-source materials) in a second subdirectory, and source code files in a third subdirectory. Unless there is a good reason to split the prints, also provide a combined 3MF file in the project directory root.

# Chore magnet fit

The user confirmed that the current chore-magnet pocket, 6.05 mm diameter by 2.1 mm deep, is a perfect fit for their 6 x 2 mm disc magnets. Reuse it as their tested starting point for these magnets and their printing setup; keep it adjustable and do not assume the same fit on every printer or filament.

For the user's printed chore magnets, 5% infill proved plenty strong enough for their intended whiteboard use, and a prime tower was unnecessary for their colour changes. Treat these as successful results for this user's setup and this type of print, not as guarantees for every model or colour-change configuration.
